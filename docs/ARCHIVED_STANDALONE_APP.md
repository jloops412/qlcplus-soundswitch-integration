# Archived Standalone Application

The repository originally explored a standalone DJ lighting application named
EmberLights. That product direction was retired after the project selected
QLC+ as the only show-time lighting application.

The following are historical and are not part of the active default branch:

- the native EmberLights engine and desktop UI;
- Studio/Runner and skin-platform plans;
- standalone Preview installers and packaging workflows;
- standalone-app parity backlogs, issues, and pull requests; and
- experimental import and replacement-product specifications tied to that
  architecture.

The history remains recoverable through Git commits, tags, and closed GitHub
records. It is retained for provenance only. Detail or recency does not make an
archived plan active.

Current development must follow:

```text
VirtualDJ -- OS2L --> QLC+
Control One -- MIDI --> QLC+
QLC+ -- SoundSwitch plug-in --> Micro or Control One DMX
```

Do not restore archived source or plans to `main` unless the project owner
explicitly reopens that direction.
