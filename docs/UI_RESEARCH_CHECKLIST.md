# UI Research Checklist

Use this short checklist when executing the detailed plan in `19_SOUNDSWITCH_UI_FORENSICS_AND_CAPTURE_PLAN.md`.

- [ ] Record SoundSwitch version, Windows version, client size, resolution, and scale.
- [ ] Capture the complete Edit Mode state matrix.
- [ ] Capture the complete Performance Mode state matrix.
- [ ] Capture connection, hardware, error, and notification states.
- [ ] Capture Autoloop selected/active/progress/exclusive/repeat states.
- [ ] Capture Static Look inclusion/off/lower-layer behavior.
- [ ] Annotate regions, controls, state, workflow, and pain points.
- [ ] Tag every derived value `MEASURED`, `ESTIMATED`, `DESIGN_TARGET`, or `BEHAVIORAL`.
- [ ] Map every critical control to a command and state key.
- [ ] Update the reference-skin deviation ledger.
- [ ] Generate golden states at required resolutions/DPI.
- [ ] Keep original evidence read-only; use EmberLights-owned assets in product skins.
