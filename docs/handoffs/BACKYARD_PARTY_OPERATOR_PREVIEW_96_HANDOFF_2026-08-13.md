## What changed

  opens no adapter or output path.
- It verifies nested raw-attempt/attestation identities plus the intrinsic
  requirement/observation structure before using prior evidence.
- It selects a completed attempt by exact universe/backend and frame matches,
  then current-project basis, stable patch, timestamp, and digest.
- It reports the authored-reference and current-routed raw requirements
  independently. For the IR-4 this can reveal, for example, authored White at
  CH4 while the current routed frame matches previously observed CH5.
- It accepts explicitly historical profile-revision evidence only while
  fixture/profile identity, manufacturer/model/mode, universe, and address
  remain stable. A repatch fails closed.
- Current Micro configured/attempted/accepted/error evidence is reported for
  the same universe/frame snapshot.
- The report always denies current fixture-side observation. A prior raw test
  and a current host-accepted write are not a current physical response.
- Existing Diagnostics Copy/Save carries the report for a recognized active
  IR-4 bench look; there is no new callback, command, output, or schema path.
