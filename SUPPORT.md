# Support

## Installation and use

Start with:

1. [the main README](README.md);
2. [the V26 package guide](releases/qlcplus-control-one/v26/README.md); and
3. [the community migration guide](docs/qlcplus-control-one/COMMUNITY_MIGRATION_GUIDE.md).

When asking for help, include:

- Windows version;
- exact QLC+ version and `qlcplus5.exe` SHA-256;
- selected SoundSwitch device and port;
- fixture model, DMX mode, universe, and address;
- the package-test result; and
- the smallest safe sequence that reproduces the problem.

Remove usernames, client or venue names, serial numbers, credentials, and
private project content before posting.

## Where to report

- Reproducible defect: use the Bug Report issue form.
- Physical hardware result: use the Hardware Test issue form.
- Proposed improvement: use the Feature Request issue form.
- Security-sensitive problem: follow [SECURITY.md](SECURITY.md).
- General QLC+ usage unrelated to this integration: use the official QLC+
  documentation and community support channels.

This community project cannot provide official SoundSwitch, inMusic,
VirtualDJ, fixture-manufacturer, or QLC+ support.
